# wizardos-spells

Wand spells, as seedbank tools. Every folder with a `seed.json` is one seed.

| Folder | What it does |
|---|---|
| `add-music/` | Download audio from a URL into a Navidrome-layout music library as tagged FLAC. |
| `yt-transcribe/` | A YouTube video's transcript as timestamped JSON, filed as a Grimoire note. |

Each depends on Wand (`github.com/etiennedoidic/wizard-apps//apps/wand@v0.1.0`) and runs as a Wand spell.
Packaged from WizardOS (`~/wizard` on the Mini, commit `4e0ee17`).
